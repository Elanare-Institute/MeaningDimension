# 著者の哲学的立場（日本語・テーゼ一覧）

作成日: 2026-10-11。Phase B。

この文書は、**著者自身が何を主張しているか**を、他者の定理や他の哲学者との対応より先に書き出したものである。ここでいう著者は本論文の著者本人である。Gödel・Feferman・西田との関係は `godel_boundary.md` と `author_position_en.md` で別に扱う。

## 優先順位の原則（著者の指示、2026-10-11）

**著者の考えを西田より上位に置く。**

1. 本論文の哲学的な基準は、著者のテーゼ（§1 の T1–T13）である。西田は、それに従属する思想的資源・比較対象として扱う。
2. 著者の定式化と西田の本文が食い違うときも、**著者の定式化を西田に合わせて修正しない**。修正するのは「西田がそう述べた」という帰属のほうだけである。
3. 西田の権威で著者のテーゼを根拠づけない。西田の本文は、著者のテーゼの証明でも、正否の判定基準でもない。
4. 西田に由来する語（行為的直観、作られたものから作るものへ）を著者が自分の意味で使うときは、**著者の用法**として明示する。西田の意味として帰属させるのは、照合済みの本文の内容に限る。

## 冒頭の要点（著者が明示したもの）

1. **現在は未来を創発し続ける。** 「いま」こそが現実を生成する場である。
2. **過去は痕跡から現在において再構成される。** 過去は直接観察できない。
3. **未来はまだ存在していない。** 完成した未来を、現在の計算で読み出すことはできない。
4. **作るものは行為的直観と不可分である。** 「作るもの」とは、今まさに作り続ける働きである。
5. **西田と著者の主張は同一ではない。** 西田の行為的直観と「作られたものから作るものへ」は重要な思想的資源だが、著者の「時間の非既成性」「未来の創発」「意味次元の生成」はそれと完全には一致しない。**基準は著者の考えであり、西田はその下に位置する。**

## 1. テーゼ一覧

各テーゼについて「主張していないこと」も併記する。主張の範囲を勝手に強めたり弱めたりしないためである（[指] §1, §7）。

### A. 時間

**T1（いまの生成性）** 「いま」こそが現実を生成する場である。過去・現在・未来を、すでに完成した時間軸上の三領域として等しく実在するものとみる図式を採らない。[指 §1.1-1]
- 主張していないこと: 特定の時間論（McTaggart の A/B 系列、現在主義、成長ブロック説など）との同一視。比較するときは、原典を照合したうえで別節で行う（[指] §5 Phase B）。

**T2（過去の再構成）** 過去は直接観察できない。現在に残る痕跡をもとに、現在の意味体系からナラティブとして再構成される。出来事と、現在におけるその出来事の意味を区別する。[指 §1.1-2]
- 主張していないこと: 「過去に出来事が起きなかった」。「客観的な出来事はなかった」。

**T3（未来の非存在）** 未来はまだ存在していない。現在すでに完成した未来を、計算で読み出すことはできない。問題にしているのは、現在の計算や予測が将来の生成可能性を尽くさないことである。[指 §1.1-3]
- 主張していないこと: 「予測は一切不可能」。「因果法則は存在しない」。「未来はすべてランダム」。「未来について数学的推測はできない」。

**T4（作るもの）** 「作るもの」とは、今まさに作り続ける働きである。行為と直観が不可分である行為的直観と結びつき、未来に開かれている。[指 §1.1-4]
- 主張していないこと: 予め定義された `next : Stage → Stage` の機械的反復と同じであること。
- ここでの「行為的直観」は**著者の用法**であり、西田本文の定義には従属しない。著者は実践者の立場から次のように理解している: 実践者（デザイナー、エンジニア）にとっては、純粋経験の中に最初から行為的直観が含まれている。「見ながら作り、作りながら見る」循環は、理論として学ぶ以前に生きられている。[行為 2025 §3–5]

**T5（意味の遡及）** 生成は未来だけでなく、過去の意味にも遡及する。新しい意味次元・イデオロギー・ナラティブが、過去の出来事の解釈を変える。[指 §1.1-5]
- 主張していないこと: 原史料の改変。当時の人物が新しい解釈をしていたと帰属させること。記憶痕跡そのものの書き換え。

### B. 意味次元生成と可能無限

**T6（意味次元生成）** 既存の語彙や命題を足すだけでなく、「何が対象か」「何が問いか」「何を証明・評価・選択できるか」という意味づけの規則と解釈の枠組みそのものが生成されうる。数学に限らず、イデオロギー、ナラティブ、歴史解釈にも当てはまる。[指 §1.2] [稿 §2.1, §2.3(5), 行95]
- 原稿の例: ℝ から ℂ へ、Hartley から Shannon へ、パーフェクトイド空間、マルクス主義やフェミニズムによる解釈枠組みの拡張。[稿 §2.1, §2.3]

**T7（可能無限）** 意味次元の生成は、完成済みの可能性の全体から選ぶことではない。未来にまだ存在しない可能性そのものが生成されうる。これは著者の哲学的立場・公理として提示する。Gödel II で証明された命題ではない。[指 §1.2] [稿 §2.3「Axiom. Meaning-dimension generation is infinitely possible」, 行97, 107, 127, 298]
- 原稿での様相: 「生成された任意の意味次元について、さらに別の次元を生成できる」。すべての意味次元が同時に存在するとも、過程が完了するとも言わない。[稿 行97]
- 原稿での potentialism との差: 可能性はあらかじめ与えられた見渡しの対象ではなく、生成の行為によって作られる（「actor's openness, not that of a landscape surveyed by a spectator」）。[稿 §6.3, 行314] [GC §8]

**T8（生成的真矛盾主義）** 矛盾を生成の契機とみる、著者固有の哲学的立場。矛盾は排除すべき誤りでも、受け入れるべき永続的な真理でもなく、移行点である。「任意の矛盾について、それを真にする意味次元がいつか生成されうる」は強い哲学的主張である。[指 §1.2] [稿 §3.1]
- 区別すること: 形式的な `φ ∧ ¬φ`、既存領域での存在要求の不充足（ℝ における x²+1=0 の根）、未決定性、未解決問題。[指 §1.2] [稿 §3.2 の四つの door]
- 主張していないこと: Lean の標準的な古典論理で、この主張をそのまま証明したということ。

**T9（量化の順序）** 「各問いについて、それを扱える後の段階がいつかある」と主張する。「すべての問いを扱える段階が一つある」とは主張しない。現在の体系の限界を、今後生成されうるすべての意味体系に投影することを否定し、そのような投影を主張する側に証明責任を置く。「いつか」は「いま」ではない。[稿 §3.3]
- 主張していないこと: 「無限に拡張可能」から「すべての問いにいつか到達可能」が導かれるということ（[指 §3.3-5]）。原稿 §3.3 も、前者を Gödel から導くとは言っていない。

**T10（発見方法論）** 可能無限を意識して使い、将来生成される意味次元が満たすべき条件から逆向きに、新しい予想や研究課題を見いだす。アブダクションとの関係を検討できる。[指 §1.2]
- 主張していないこと: IBE、creative abduction、transformational creativity との差が「証明済みの独創性」であること。
- **原稿 PhilMath2.tex にはこのテーゼの記述がない。** 付録34の「meaning-dimension inexhaustibility」は別論文の予想であり、このテーゼそのものではない。

### C. 反プラトン主義と潜在主義との距離

**T11（発見ではなく生成）** 意味次元は既存の隠れた真理の貯蔵庫から取り出されるのではない。ℂ の構成以前に「i² = −1」は真理値を持たなかった（知らなかったからではなく、ℝ の体系ではその問いに意味がなかったから）。[稿 §2.4, §6.1]

**T12（行為者の開放性）** 生成の開放性は、見渡す者の開放性ではなく、行為する者の開放性である。[稿 §6.3] [GC §8]

### D. 西田に対する著者の位置

**T13（著者が上位、西田は資源）** 著者の時間論と意味次元生成論は、著者自身の哲学である。西田の行為的直観と「作られたものから作るものへ」は重要な思想的資源の一つだが、著者の「時間の非既成性」「未来の創発」「意味次元の生成」とは完全には同一でなく、それらを基礎づけるものでもない。[指 §1.3]、著者の指示（2026-10-11）
- 著者はすでに、実践者の立場から西田を「乗り越える」読みを示している（純粋経験から行為的直観への展開は、理論家としての「迂回」だった）。[行為 2025 §5, §7]
- 主張していないこと: 「西田本人がそう言った」「西田の原典から当然に導かれる」。そう言えるのは、原典の該当箇所を照合したものに限る（照合結果は `author_position_en.md` §3）。
- 西田から導かないこと: 「作られたものに作る働きを混ぜるべきではない」という規則。公理表示と証明可能性関係への静的な一対一対応。[指 §1.3, §2]

## 2. 撤回された立場

- **made-canonicity** とそれを支えた「made-to-making asymmetry」の静的な読み（公理 = made、証明可能性 = making、「never in reverse」）は、著者の立場ではない。詳細は `retired_made_canonicity.md`。
- 作られたものと作る働きの関係は、不可分で動的なものとして再検討する。[指 §2]
