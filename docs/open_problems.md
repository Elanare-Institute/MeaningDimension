# Open problems（重要度順）

## A. 論文の中心に関わる未解決課題

1. **made-canonicity 条件 (ii) の非自明で安定した形式的定義。**
   構文的な読み（ii-S）は論理的同値な書き換えに対して不変でない（`made_canonicity_audit.md` C1, C2′）。不変な読み（ii-I）として「T で証明可能に Σ₁ 論理式と同値」を採ると、(ii) は (i) に吸収されて独立な内容を失う。候補は (a) 規範的条件として明示的に数学の外に置く、(b) 「表示を計算する手続き」（Turing 機械の番号など）のレベルで定義する、のいずれかと思われるが、(b) で無矛盾性文が T 上一意に定まるかは**不明**であり、C2 の構成は (b) でも再現できる可能性が高い（未検討）。
2. **(ii) が D1–D3 の導出と規範的正準性のそれぞれに何を追加するか。**
   D1–D3 の導出には (ii) は寄与しない（新稿自身の議論でも）。規範的正準性（「その」無矛盾性文を選ぶこと）については、(i)+(ii-S) では足りない（C2、Lean の M4–M5）。(ii) を強めて C2 型の表示を排除できるかが問題。
3. **意味次元生成を単なる理論拡張と区別する判定基準。**
   本プロジェクトの形式化は「理論拡張」と「構造（解釈）の変更」の二種類しか扱っていない。§3.2 の door や「新しい proof principle」「新しい logic」を区別する数学的基準はない。
4. **「可能無限」と「任意の問いの将来到達可能性」のギャップ。**
   G4（∀∃: 適格な段階には適格な真の拡張がある）は前者の算術版であり、後者（∀ 問い ∃ 段階）を含意しない。後者の算術版は Turing–Feferman の超限的完全性であり、順序数記法の非実効的選択に依存する。
5. **標準的な Gödel II の既知の帰結を超える、真に新しい数学的命題の有無。**
   現時点で本プロジェクトの Lean 定理はすべて既知の定理・その系・初等的事実である（`theorem_ledger.md`）。C4（D1–D3 を満たし T 上 Σ₁ と同値でない provability predicate の存在）は論文の「開いた逆向き」への回答だが、初等的で民間伝承である可能性が高く、新規性は主張しない。
