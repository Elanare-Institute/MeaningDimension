# Made-canonicity の監査（Phase 3 予備）

対象: 新稿 §3.5–§4.2、Definition 1。**made-canonicity が成り立つことを前提にせず**、定義の各読みについて反例を探した。

凡例: **[Lean]** = Lean で証明済み（`MeaningDimension/Godel/MadeCanonicity.lean`、commit `a1b115e`） / **[紙]** = 紙上の証明（未形式化。標準的事実に依存） / **[文献]** = 原文で確認した既知結果。

## 1. 定義と三つの読み

> **Definition 1.** 再帰的可算理論 T の表示 α(x) が made-canonical であるとは:
> (i) α(x) は Σ₁ である。
> (ii) α(x) は自身が定義する体系の証明可能性関係の情報を埋め込まない。すなわち α-公理からの証明・反駁・導出の非存在を主張する Π₁ 節が α の定義の一部になっていない。

(i) は明確に形式化できる（ただし「T が α(n) を各公理 n について証明する」こと、すなわち T における数え上げも要る。Σ₁ で ℕ で正しければ Σ₁ 完全性から自動的に従う）。

(ii) には少なくとも三つの読みがある。これらは別物で、混同しない。

| 読み | 内容 | 判定可能性 | 論理的同値な書き換えに対して |
|---|---|---|---|
| **(ii-S) 構文的** | α の論理式の中に「α-公理からの証明の非存在」を表す Π₁ 部分式が現れない | 論理式を見れば判定できる（ただし「〜を表す」の特定が必要） | **不変でない**（§3） |
| **(ii-G) 一般的** | α は証明可能性関係について**いかなる情報も**埋め込まない（新稿 (ii) の前半の文言） | 定義されていない。構文的な代用は §3 C2′ で破れる | 不明 |
| **(ii-I) 不変的** | 「T で証明可能に同値な書き換え」を法とした性質として定義する（例: α が T で証明可能に Σ₁ 論理式と同値） | T の定理集合に依存し、一般に決定不能 | 不変（定義により） |
| **(ii-N) 規範的** | 「made だけを記述している」という人間の判断 | 数学的には判定しない | — |

## 2. D1–D3 の導出に何が使われているか

- 新稿 §4.2 の議論そのものが、D1 と D3 を (i) から、D2 を任意の数え上げについて導いている。**(ii) は導出のどこにも使われていない。**
- [文献] Σ₁ 数え上げについて G2 が成り立つことは Feferman (1960) による既知の結果（Cheng, *Current research on Gödel's incompleteness theorems*, BSL 27 (2021), arXiv:2009.04887 の要約で確認）。
- [Lean/既存] Foundation の Gödel II は、さらに強い仮定（**IΣ₁ で証明可能に Δ₁** な表示、`Theory.Δ₁`）の下で証明されている。`dependency_audit.md` §4.1。
- **結論**: 「D1–D3 は made-canonicity の帰結」は正しいが、実質は「D1–D3 は (i)（＋数え上げ）の帰結」であり、Hilbert–Bernays–Löb と Feferman 1960 による**既知**の結果である。(ii) が追加するのは哲学的な理由づけであって、D1–D3 の数学的導出ではない。

## 3. 条件 (ii-S) への反例（構文的な読みは書き換えに不変でない）

**C1（無害なのに (ii-S) に違反する表示）** [紙]
T ⊇ PA を α で数え上げる。固定した数項 k について
`α_k(x) := α(x) ∧ ¬∃y Prf_{α↾k}(y, ⌜0=1⌝)`。
α_k は「α-公理（コード k 以下）からの 0=1 の証明の非存在」を主張する Π₁ 節を含むので (ii-S) に違反する。しかし PA は本質的に反射的（Mostowski）なので T は有限部分理論 α↾k の無矛盾性を証明し、`T ⊢ ∀x (α_k(x) ↔ α(x))`。したがって `Prov_{α_k}` と `Prov_α` は T で同値で、D1–D3 も成り立ち、`Con_{α_k}` は `Con_α` と T で同値（したがって証明不能）。
同じことは前稿の α*（**有界**版 `¬∃y<x Prf_α(y, ⌜0=1⌝)`）にも言える。これは Δ₀ 節なので α* は Σ₁ のままで、Feferman の定理により `Con` は証明不能である。

→ (ii-S) は、生成的に振る舞う（G2 が成り立つ）表示を除外してしまう。

**C2（(ii-S) を満たすのに無矛盾性文が変わる表示）** [Lean：述語レベル / 紙：表示レベル]
`α'(x) := α(x) ∨ (x = ⌜0=1⌝ ∧ Pr_α(⌜¬Con_α⌝))`。
- α' は Σ₁ で、Π₁ の非存在節を含まない。(i) と (ii-S) を満たす。
- T が Σ₁ 健全なら `Pr_α(⌜¬Con_α⌝)` は偽なので、α' は ℕ で α と同じ公理集合を定義する。
- T の中では `Pr_{α'}(x) ↔ Pr_α(x) ∨ Pr_α(⌜¬Con_α⌝)`（場合分け）[紙]。
- この右辺の述語 `□'σ := □σ ∨ □(¬Con)` について [Lean]:
  - D1–D3 を満たす（`disj_HBL`、任意の π で成立）；
  - ℕ で外延的に正しい: `ℕ ⊧ □'σ ↔ T ⊢ σ`（`standard_disj_models_iff`）；
  - `T ⊬ Con → Con'`（`standard_disj_con_not_implied`）、`T ⊢ Con' → Con`（`standard_disj_con_implies`）；
  - Gödel II は □' でも成り立つ: `T ⊬ Con'`（`standard_disj_con_unprovable`）。
- 実際 `Con' ↔ Con ∧ ¬□(¬Con)`（`disj_con_iff`）で、これは T 上 `Con(T + Con(T))` と同値 [紙：形式化された演繹定理が必要]。

→ made-canonicity（(i)+(ii-S)）は、無矛盾性文を **T で証明可能な同値を法としても一意に決めない**。新稿の「made-canonicity は哲学的に正当化された無矛盾性文を選ぶ」という主張は、(ii) をさらに強めない限り成立しない。

**C2′（(ii-G) を構文で代用できない）** [紙]
C2 の `Pr_α(⌜¬Con_α⌝)` を、MRDP 定理により IΣ₁ で同値なディオファントス文 `∃z̄ (p(z̄) = q(z̄))` に置き換える（MRDP は IΔ₀+exp で形式化可能: Gaifman–Dimitracopoulos 1982。**原典は未確認**）。置き換えた α'' は構文上、証明についてまったく言及しないが、T における振る舞いは α' と同じである。
→「証明可能性の情報を埋め込む」を構文的な性質として定義すると、この書き換えで判定が変わる。(ii-G) は構文的な性質ではありえず、定義するなら (ii-I) か (ii-N) になる。

## 4. 新稿の「開いた逆向き」への回答

新稿 §4.2: 「D1–D3 が逆に made-canonicity を強制するかは未解決。Σ₁ より複雑で D1–D3 を全部満たす provability predicate は示されていない」。

**C3（構文的な読み）** [紙・自明] `Pr(x) ∧ ∀y (y = y)` や C1 の `Pr_{α_k}` は構文上 Σ₁ でなく、T で `Pr` と同値なので D1–D3 を満たす。構文的な読みでは問いは自明に否定的に解決する。

**C4（T で証明可能な同値を法とする読み）** [D1–D3 部分は Lean、Σ₁ 非同値性は紙]
T を Σ₁ 健全、`π := ¬RFN_{Σ₁}(T)`（一様 Σ₁ 反映の否定、Σ₂ 文、ℕ で偽）として
`Pr''(x) := Pr_T(x) ∨ ¬RFN_{Σ₁}(T)`。これは表示 `α''(x) := α(x) ∨ (x = ⌜0=1⌝ ∧ ¬RFN_{Σ₁}(T))` の provability predicate と T 上同値である [紙]。
- D1–D3 を満たす: [Lean] `disj_HBL`（π は任意の文でよい）。
- ℕ で外延的に正しい: RFN_{Σ₁}(T) は T の Σ₁ 健全性から真 [紙]。
- **T で証明可能に Σ₁ 論理式と同値にはならない** [紙]:
  `Pr''(x) ↔_T σ(x)`（σ は Σ₁）とすると、`Pr''(⌜⊥⌝) ↔_T ¬RFN`（RFN は Con を含意するので）より `RFN ↔_T ¬σ(⌜⊥⌝)`、すなわち RFN_{Σ₁}(T) が T 上 Π₁ 文 π₁ と同値になる。π₁ は真なので T+π₁ は無矛盾。T+π₁ は RFN の事例 `Pr_T(⌜¬π₁⌝) → ¬π₁` を証明するから `T+π₁ ⊢ ¬Pr_T(⌜¬π₁⌝)`、すなわち `T+π₁ ⊢ Con(T+π₁)`。これは T+π₁ に対する Gödel II に反する。
- 無矛盾性文は `Con'' ↔_T RFN_{Σ₁}(T)` であり、G2 はここでも成り立つ（T ⊬ RFN_{Σ₁}(T)）。

→ D1–D3 は条件 (i) を、T で証明可能な同値を法としても**強制しない**。新稿の言い方では「made-canonicity は D1–D3 より真に強い」側に決着する。ただし α'' は G2 の意味で「生成的」に振る舞う（無矛盾性文は証明不能）ので、(i) は G2 が成り立つための**必要条件でもない**。

新規性: 初等的な議論で、民間伝承である可能性が高い。確認した範囲（Kurahashi 2020 *A note on derivability conditions* の要旨、Cheng 2021 の要約、Kurahashi 2021 の本文 §3）には明示的な記述がなかった。**新しい定理とは主張しない**。網羅的な文献調査ではない。

## 5. Rosser 述語と Feferman の α*

- [文献] Kurahashi, *Rosser provability and the second incompleteness theorem*（arXiv:1902.06863）**Corollary 3.3**:「There exists no Rosser provability predicate of T satisfying both D2 and D3.」本文で確認した。新稿の引用は正確。理由は新稿・前稿の説明どおり（D1 は成立し Con^R は証明可能なので、Löb の議論から D2∧D3 は不可能）。
- Rosser 型は**表示 α ではなく provability predicate 自体の変更**である。新稿も「this time into the provability predicate rather than the axiom enumeration」と区別している。
- [紙] 新稿版の α*（非有界、`α↾x`）について:「Con_{α*} が証明可能」という議論（証明の最大の公理 x の連言がその証明を否定する）は IΣ₁ 程度で形式化でき、T の反射性を要しない。一方「α* が T で数え上げる（D1）」には T が各 `α*(n)` を証明すること、すなわち有限部分理論の無矛盾性の証明（PA の拡張なら本質的反射性で成立）が要る。新稿の「α* が失敗するのは D3」は T ⊇ PA の場合に正しく、有限公理化された T では D1 が失敗しうる。
- Foundation の `Theory.Δ₁` は α* を表現できない（Σ₁∧Π₁ は IΣ₁ で証明可能に Δ₁ ではない）。α* の形式化は抽象 provability 層で行う必要があり、未着手。

## 6. 新稿 §4.2 の D3 導出の誤り（修正提案）

新稿は D3 の根拠として `T ⊢ φ ⇒ T ⊢ Prov(⌜φ⌝)`（Σ₁ の φ について）を表示している。これは推論規則（D1 の Σ₁ 制限）であって、D3 に必要なのは**内部の含意** `T ⊢ σ → Prov(⌜σ⌝)`（形式化された Σ₁ 完全性）である。前稿の脚注49 は正しい形だった。Foundation では `provable_sigma_one_complete : 𝗜𝚺₁ ⊢ σ 🡒 □σ`（Σ₁ の σ）→ `provable_D3`。

## 7. まとめ（Lean で示したこと／示していないこと）

示したこと [Lean]:
1. 任意の provability □ と任意の文 π について、`□ ∨ π` は D1–D3 を保存する。
2. 算術の Σ₁ 健全な T について、ℕ で正しく D1–D3 を満たす二つの provability で、T 上同値でない無矛盾性文を持つものがある。

示していないこと:
- made-canonicity（特に (ii)）の形式的定義。**定義していない**。
- C2 の表示 α' と述語 □' の T 上の同値（表示レベルの主張）。
- C4 の「Σ₁ と T 上同値でない」部分。
- made-canonicity の哲学的正当化。これは数学の範囲外である。
