## 1. Lean で検証したのは何か

すべて「明示された形式言語（ℒₒᵣ）・古典一階論理・Δ₁ 表示された理論・標準モデル ℕ」の下の命題である。

| 論文の語彙 | Lean で検証した数学的対応物 | 対応の性格 |
|---|---|---|
| *incorporation*（§3.4 iii） | G1: `T ⪱ T ∪ {Con_T}` | Gödel II そのもの（既知） |
| *non-completion*（§3.4 iv） | G2/G4: Σ₁ 健全な Δ₁ 表示の理論の有限段階はどれも最終でない。L2.2 で Σ₁ 健全性が伝播する | Gödel II の反復（既知の系） |

| ω 段階（Turing–Feferman の有限部分） | G3: T ∪ {¬□ⁿ⊥} の Δ₁ 表示についても上昇は止まらない | 既知の系 |
| §3.3 の量化順序 | どの適格な段階も全真理を証明しない（∃∀ の否定） | 既知の系 |

## 2. Lean で検証していないもの（分類 D のまま）

以下はどれも Gödel II からも本プロジェクトの定理からも**導かれていない**。Lean の `Prop` として書いてもいない。

1. **意味次元生成の可能無限性の公理**（§2.3）。G4 は Δ₁ 表示された算術理論の族についての定理であり、「意味次元」一般についての主張ではない。G4 の `Eligible` は Σ₁ 健全性という強い仮定を含み、人間の意味生成とは無関係な、理論の構文的・算術的な性質である。
2. **生成的真矛盾主義**（§3.1）。Lean で示せたのは逆向きの no-go（同じ解釈では反証済みの文は真にならない）と、解釈を変えれば**別の**評価が得られるという事実だけである。「矛盾がいつか真になる」は形式化していない。
3. **「各問いがいつか handled される」**（§3.3）。Turing–Feferman の超限的完全性定理は未形式化で、しかもそれは算術の文に限られ、順序数記法の選択に依存する（論文自身が注意している）。
4. **made-to-making asymmetry による made-canonicity の正当化**（§3.5, §4.1）。条件 (ii) は形式的に定義されておらず、構文的な読みは論理的同値な書き換えで判定が変わる（`made_canonicity_audit.md` §3）。
5. **反プラトン主義・反標準的真矛盾主義・反潜在主義**（§6）。
6. **LLM が意味次元生成をできないという主張**（§7.2）。
7. **五つの portrait の分類ラベル**（generative / inert / halting / explosive / vacuous）が「予測的」であるという主張（§5）。Portrait 3 の数学的内容（G2-sharp）と Portrait 1 の内容（G1/G2）は検証したが、ラベルの付け方自体は哲学的分類である。

## 3. 注意すべき混同

- **内部と外部**: `T ⊢ Con_T`（内部の証明可能性）と `Consistent T`（メタレベルの無矛盾性）と `ℕ ⊧ Con_T`（外部の真理）は別。L2.2 の証明はこの三つを明示的に行き来する（`models_consistent`）。
- **健全性の段階**: `Consistent` ⊊ `Σ₁-sound` ⊊ `ℕ ⊧* T`。G2 は Σ₁ 健全性を、G3 はより強い ℕ 健全性を仮定している。G2-sharp は無矛盾性では足りないことを示す。
- **表示依存**: Foundation の `Con_T` は `T.Δ₁` インスタンス（表示）から作られる。G1–G4 の「無矛盾性文」は Foundation が和集合に与える標準的な表示から作ったものである。
- **ℂ は ℝ の矛盾を真にしていない**: ℝ で偽な文が ℂ で真になったのは、評価する構造が変わったからである。ℝ の理論は ℂ で保存されない（P1.3d）。
