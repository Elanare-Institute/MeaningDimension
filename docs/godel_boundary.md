## 2. 数学からは導かないこと（新指示書 §3.1）

以下は Gödel II からも、本プロジェクトのどの Lean 定理からも導かれない。原稿でそう読める文は書き換える。

1. 未来がまだ存在しないこと（T3）、いまが現実を生成すること（T1）。
2. 行為的直観（T4）、過去の再構成や意味の遡及（T2, T5）。
3. 意味次元一般の可能無限（T7）。
4. あらゆる矛盾がいつか真になること（T8）。
5. 人間の意識や記憶についての主張。
6. LLM が原理的に意味次元を生成できないこと（原稿 §7.2）。
7. 数学的プラトン主義が誤りであること（原稿 §6.1）。Gödel II はこの点で中立である。Gödel 自身はプラトン主義者で、不完全性からプラトン主義的な帰結を引き出そうとした（GC 論文 §8 自身がこれを認めている。一次資料の照合は Phase E）。

## 4. 中心問題の定式化（新指示書 §3.2）

**形式的生成の非完結性**（数学）:
- M-G4: 適格な段階 S には、つねに適格で真に強い S' がある。しかも S' = next(S) は S から**計算で決まる**。
- M-R: 実効的に指定された健全な拡張手続きは、合併まで含めて算術的真理を尽くさない。

**意味生成そのものの開放性**（著者、T3・T7）:
- 現時点の記述体系は、未来の意味可能性の全体を先取りして定義できるとは限らない。可能性そのものが、まだ存在しない。

**両者の関係**:
1. 前者は、**事前に完全に決まった手続き**についての否定的結果である。「決まっていても閉じない」。
2. 後者は、**まだ決まっていない**ことについての存在論的主張である。
3. 共通しているのは「現在指定できるものは、全体を尽くさない」という形式だけである（B5）。前者は後者の**限定的な部分モデル**であって、証明ではない。
4. 前者の数学は、到達の標的（標準模型での算術的真理）を固定して前提している。後者は、評価の枠組みそのものが生成されると言う（T6, T11）。この点で、前者を後者のモデルとして使うと、反プラトン主義と緊張する。論文はこの緊張を隠さずに扱う必要がある。
